# Advent of Code 2022 - OCaml

OCaml solutions for [Advent of Code 2022](https://adventofcode.com/2022).

## Solutions

Days 1-18 implemented in `bin/day*.ml`.
Day 19 in progress

## Build & Run

```bash
dune build
dune exec aoc
```

To run a specific day, edit `bin/main.ml` to call the desired day module.

## Requirements

- OCaml
- Dune >= 3.6
